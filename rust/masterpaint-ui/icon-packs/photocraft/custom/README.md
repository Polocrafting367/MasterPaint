Icônes dessinées pour MasterPaint (polocrafting, 2026) là où le projet de référence n'a pas
d'équivalent. Elles ne viennent pas de PhotoCraft / Lucide : à garder à part de ses fichiers d'origine.
Style : Lucide, trait de 2 px. Nom de fichier = nom MasterPaint de l'icône. Générées par
tools/gen_custom_pack_icons.py ; on peut aussi les retoucher ici à la main (relancer ensuite
tools/build_reference_packs.py, sans relancer ce script, sinon les retouches sont écrasées).
