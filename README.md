## À propos

<p align="center">
  <img src="icons/icon.svg" width="64" height="64" alt="MasterPaint" />
</p>

Inspiré de Paint.NET, Photoshop et Illustrator. Créez des images bitmap et vectorielles au même endroit, sans publicité ni traceurs. Tout fonctionne à 100 % en local, sans envoi de données : le navigateur utilise localStorage pour un stockage temporaire sur votre machine.

## Fonctionnalités

| | |
| :--- | :--- |
| Formes & calques | Bitmap et vectoriel, calques et formes modifiables |
| Dessin | Pinceau, crayon, gomme, pot de peinture, dégradé |
| Effets | Filtres accélérés WebGL / WebAssembly |
| Outils | Déformation, perspective, sélection et alignement |
| Interface | Disposition Paint.NET, Photoshop ou téléphone |

## Démarrage

**En ligne** — [polocrafting.fr/Illu](http://polocrafting.fr/Illu)

**En local**

```bash
git clone https://github.com/polocrafting/MasterPaint.git
cd MasterPaint
php -S localhost:8000
```

Puis ouvrez [http://localhost:8000](http://localhost:8000) (ou `index.html` directement).
