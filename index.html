    À propos de l’application

    Application développée par polocrafting 367

    Interface et logique créées par IA.

    Langue de l’interface

    Raccourcis clavier ▶

    • Touches outils (sans Ctrl) : …
    • Ctrl+Z / Ctrl+Y · Ctrl+Maj+Z
    • Ctrl+A · Échap / Ctrl+D
    • Ctrl+Maj+X : Régler la zone de travail à la sélection
    • Ctrl+C V X · Suppr / Retour arrière
    • Ctrl + molette : zoom (100 % = toile entière dans la zone) · molette : déplacer la toile
    • Maj + tracé : proportions / angles · Ctrl+Maj+H V C centrer · Maj+B pinceau
    • [ ] taille pinceau / crayon / gomme
    • Déplacer : flèches 1 px · Ctrl + flèche 10 px
    Apparence

    Disposition de l’interface

    Paint.NET : fenêtres volantes. Photoshop : colonnes. Téléphone : menu ☰ et panneaux compacts.

    Souris et tactile sont pris en charge partout ; aucun réglage séparé n’est nécessaire.

    Couleur d’accentuation

    Menus actifs, contours de focus et curseurs des réglages.

    Performances
    Moteur WebAssembly (WASM) : Accélération des filtres et du RAW
    Utilise le code natif pour une fluidité maximale. Désactiver si vous constatez des décalages visuels.
    Pinceau / crayon : aperçu allégé pendant le tracé
    Désactive temporairement les filtres dynamiques et les masques α sur les calques pour un tracé plus fluide ; rendu complet au relâchement.
    Miniatures : onglets documents et liste des calques
    Désactiver pour alléger l’interface et le coût des aperçus (grands projets, machines modestes).
    Effets Windows 11 (Arrondis & Flou)
    Active les coins arrondis et les effets de flou translucide sur les fenêtres du Flat Design.
    Aperçu de l'onglet en arrière-plan
    Affiche le haut du projet actif en arrière-plan de l'écran.
    Nombre d’étapes d’historique (mémoire) :
    Les plus anciennes étapes sont supprimées et les tampons pixel libérés. Réduire la valeur allège la RAM.
    Données
    Miroir session (sessionStorage)
    Copie le manifeste dans sessionStorage (cet onglet). Si localStorage est plein, la copie peut quand même être enregistrée ; au rechargement, si le manifeste principal est absent, Illu tente de rouvrir depuis ce miroir. Sans option cochée, seul localStorage est utilisé.
